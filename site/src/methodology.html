Data

The file is application_train.csv from the Kaggle competition Home Credit Default Risk. It has {{f:n_raw}} loans and {{f:n_cols}} columns. The test file has no labels and is not used. The {{f:n_aux_tables}} other tables are not used. {{tag:doc}}

Split design

One stratified split, made once from the labelled file, with seed {{f:seed}}. Stratified means each part keeps the same share of loans with payment trouble.

Integrity checks

  • Duplicate rows in the file: {{f:dup_rows}}. Duplicate loan IDs: {{f:dup_loan_numbers}}. {{tag:data}}
  • TARGET has two values, zero and one, and {{f:target_missing}} missing. {{tag:data}}
  • The raw file was only read, never changed. Its checksum was the same before and after the run. {{tag:data}}

How the numbers are made

  • A build script reads the train split and writes aggregated files. The page text takes every number from one facts file, so no number is typed by hand into the copy.
  • Build checks fail if a number in the text is not in the facts file, if any file looks like raw data, if a link is broken, or if the site is too large.
  • Column descriptions on the Feature Explorer are from {{desc_source}}.
  • Blocks drafted by AI and not yet adopted by the author carry a label at the top: "{{config:ai_draft_label}}". The author's own text carries a different label. The author can change the wording with one setting.

Data handling

Only aggregated figures are shown: counts, rates, bins and summary values. No rows, no loan IDs, and no sample values are on this site. Groups with fewer than {{f:min_cell}} loans are hidden, so that no single loan can be picked out. Kaggle does not allow the raw file to be shared, so it is not.

Limitations

  • The table holds granted loans only, as far as we can tell. Results do not describe all applicants. {{tag:general}}{{tag:nv}}
  • The source and timing of the external scores are not documented. If they hold later information, results would be inflated. {{tag:hyp}}
  • The signal figures look at one column at a time. They do not show what a column adds inside a model.
  • The shortlist, the corruption candidates and their predictions were drafted with AI help and are not yet adopted by the author.
  • Sensitive columns are shown as descriptive data only. This project does not use them to make decisions about people. A fairness review is out of scope for this phase.
  • No model has been trained, so there are no model results on this site.

Reproduce

With the Kaggle file in place, the repository rebuilds every figure. See the project repository for the exact commands and the dependency lock file.
